# Security

Please do not open a public issue for a suspected credential leak, private-data exposure, or security vulnerability.

Until a dedicated security contact/process is published, use GitHub's private vulnerability reporting feature when available.

## Scope

Security-sensitive areas include:

- command execution and runner boundaries
- evidence/artifact handling
- path and URI handling
- signing/attestation logic
- accidental inclusion of production logs, credentials or private topology data

Do not commit real credentials, production evidence bundles, customer data, internal endpoints or secrets to examples or tests.
