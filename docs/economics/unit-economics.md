# Unit Economics

AI Factory economics should connect infrastructure cost to productive AI output.

## Cost layers

- facility CapEx
- IT CapEx
- electricity
- cooling
- network
- storage
- software / licenses
- operations / maintenance

## Production metrics

- Productive GPU Hours
- Model Progress / Time
- Goodput
- Tokens / GPU-hour
- Tokens / kWh
- Cost / 1M Tokens
- Cost / Successful Task

## Revenue metrics

- Revenue / GPU-hour
- Revenue / Rack
- Revenue / MW
- gross margin
- utilization-adjusted ROI

## Energy-to-value loop

```text
Electricity
 -> Compute
 -> Useful Token / Model Progress
 -> Business Outcome
 -> Revenue
```

PUE and GPU utilization remain useful operational metrics, but they are not the final economic objective.
