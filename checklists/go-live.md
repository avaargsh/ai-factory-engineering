# Go-Live Checklist

- [ ] FAT / SAT / IST complete where applicable
- [ ] configuration and version baseline captured
- [ ] GPU health and sustained burn passed
- [ ] PCIe / NVLink / NVSwitch checks passed
- [ ] RDMA / NCCL scale test passed
- [ ] storage / checkpoint / restore validated
- [ ] queue / quota / gang scheduling validated
- [ ] representative training/inference benchmarks passed
- [ ] TTFT / TPOT / Goodput or training progress baseline recorded
- [ ] power/cooling fault drill completed
- [ ] node/GPU/NIC/fabric failure recovery tested
- [ ] observability dashboards and alerts validated
- [ ] rollback procedures reviewed
- [ ] evidence package archived
